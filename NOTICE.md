# Upstream and Third-Party Notices

PICOSplat Extensions builds on PICO Technology's PICOSplat plugin for Unreal Engine. This repository contains the plugin source together with extensions for appearance control, filtering, spatial culling, Gaussian asset sequence playback, and native cubemap capture.

## PICOSplat Unreal Engine plugin

- Upstream: [Pico-Developer/splat_unreal](https://github.com/Pico-Developer/splat_unreal)
- Upstream license notice: [LICENSE.md](LICENSE.md)
- Target engine version: Unreal Engine 5.5

Original copyright notices are preserved in the source files.

## PICO splat components

The PLY importer and shared shader components originate from [Pico-Developer/splat](https://github.com/Pico-Developer/splat). Their MIT license notices are preserved at:
